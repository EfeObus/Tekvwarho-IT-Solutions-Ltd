## Mobile Responsive Considerations

### Navigation
- Hamburger menu on mobile
- Full-screen overlay navigation
- Logo remains visible

### Hero Sections
- Stacked layout (vertical)
- Reduced padding
- Single CTA button

### Cards/Grids
